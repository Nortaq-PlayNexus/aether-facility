## [1.0.0] — 2026-01-01

### Added
- 28 vetted public/government sources (18 active).
- SHA-256 fingerprinting and automatic de-duplication.
- Interactive command center menu.
- Scout sweep with metadata indexing and optional media download.
- Archive routing by classification.
- Status report generation (Markdown + CSV + JSON + SQLite).
- Single-file .exe build via PyInstaller.
- Zero pip dependencies — pure stdlib Python.
